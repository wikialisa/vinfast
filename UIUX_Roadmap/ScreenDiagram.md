## How to integrate
1. Add the generated routes to your `MaterialApp`:
   ```dart
   import 'package:vinfast_core/screens.dart';

   MaterialApp(
     initialRoute: '/screen1',
     routes: generateRoutes(),
   );
   ```
2. Each screen automatically receives the shared design‑system tokens via `BaseScreen`.
3. Extend any screen by editing `PrototypeScreen` in `lib/vinfast_core/screens.dart`—the table and diagram will still reflect the navigation pattern.
